関数の値渡しに注意
1. c言語において変数は値渡しとして受け取られる。
2. そのため、関数内で変数の変更を行ったとしても、その変更は呼び出し元の変数には影響しない。
3. 呼び出し先の関数で呼び出し元の変数を変えたい場合には、変数のアドレスにアクセスして変更すれば良い。


関数の引数の渡し方について
1次元配列のとき、
void func(int *A); と void func(int A[]);
は同じ意味であり、このとき引数は int *A でも int A[] でも受け取れる。

しかし二次元配列のとき、
void func(int **A); に対して 引数 int A[N][M]では受け取れない。
int **A はポインタのポインタであり、int **A をメモリの動的確保して渡すしかない。
二次元配列の正しい宣言と引数は
void func(int A[][M]); と void func(int (*A)[M]); であり、
これに対応する引数は int A[N][M];　である。
なお、C言語において関数の引数として二次元配列を宣言する場合には、
列数の値が必須である(ここではM)。
(なぜなら、Mがわからないと A[i][j]のアドレスが計算できない。
-> 関数に int A[10][20]などを渡す時、渡されるのは配列の先頭アドレスのみであり
配列の構造などの情報は保持されない。)
